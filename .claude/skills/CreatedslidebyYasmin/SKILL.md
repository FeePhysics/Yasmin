# CreatedslidebyYasmin — สไลด์ติวข้อสอบ (ข้อจริง + Mock Test + เฉลย)

สคริปต์ที่ใช้จริงอยู่ในโฟลเดอร์นี้ (`deck/` + `gen3.py` สำหรับฟอนต์) สร้างได้ด้วย
`cd deck && python3 build.py && node pdf.js` (ต้องมี Playwright; ผลลัพธ์ `../deck.pdf`)
ไฟล์ตรวจ: `audit.js` (หาบรรทัดกำพร้า/ตัวเลขแยกจากหน่วย), `sheet.py` (รวมภาพย่อไว้ดู)
**ใส่ข้อสอบใหม่:** เขียน `data_*.py` ใหม่ตามรูปแบบ `item(q, steps, ans)` แล้วเพิ่มเข้า `build.py`/`extras.py`

## 1. ขั้นตอนการทำงาน
1. **อ่านไฟล์ข้อสอบ** (pdftotext + pdftoppm ดูภาพ) จดเลขข้อ หัวข้อ ตัวเลข รูปภาพ ถ้ามีรูป (แผนภูมิ ลูกบาศก์ ตัวอักษร ตารางพิกัด) ให้ crop จากหน้า PDF ที่ 300–400 dpi หรือวาดใหม่เป็น SVG
2. **สร้างข้อเสมือน 2 ข้อต่อ 1 ข้อจริง** ใช้ความคิดเดียวกัน เปลี่ยนตัวเลขและสถานการณ์ (ไม่ซ้ำกัน) ให้คำตอบเป็นจำนวนเต็มบวกไม่เกิน 3 หลักเหมือนข้อสอบจริง และมีคำตอบเดียวเสมอ (ตรวจด้วยโปรแกรม เช่น ข้อสร้างเลขตามเงื่อนไขต้องมี 1 คำตอบ ถ้าไม่มีให้ปรับเงื่อนไข)
3. **เขียนข้อมูลในโค้ด คำนวณคำตอบด้วยโปรแกรม + assert** ทุกข้อ ห้ามพิมพ์คำตอบมือ
4. **สร้างสไลด์**: หน้าปก → สารบัญ → ข้อละ 6 หน้า: ข้อจริง, เฉลย, Mock Test 1, เฉลย, Mock Test 2, เฉลย
5. **ตรวจทาน** (ข้อ 5 ด้านล่าง) → ส่งไฟล์ → รายงานตามจริงว่าเปิดดูภาพหน้าไหนบ้าง และข้อไหนที่ตีความโจทย์เอง
6. สรุปคำตอบครูแยกไฟล์ 1 หน้า (`key.html`) + ใบสรุปจุดสังเกต/ข้อควรระวัง (`extras.TIP/WARN`)

## 2. หน้าตาที่ครูกำหนด (ห้ามเปลี่ยนถ้าไม่ได้ขอ)
- **ขนาด** A4 แนวนอน 297×210 มม. (841.92×594.96 pt) ส่งเป็น **PDF** (GoodNotes นำเข้าคมชัดที่สุด) มีสารบัญกดข้ามข้อ
- **หน้าปก**: ภาพที่ครูส่งมา (Sigma Junior ป.5, 16:9) วางเต็มความกว้างไม่ตัด ส่วนบน-ล่างเติมด้วยภาพเดียวกันที่เบลอ (`cover_blur.jpg`) ถ้าครูส่งภาพใหม่ ให้ใส่ที่ `assets/cover2.jpg` + ทำ `cover_blur.jpg` ใหม่ (ย่อ 420×240 + GaussianBlur)
- **ไม่มีลายน้ำ** กรอบ "วิธีคิด" พื้นขาว ขอบประ
- **สี**: ข้อจริง = โทนครีม-ส้ม-เหลือง (แถบหัวส้ม พื้น `bg_real.jpg` เหรียญส้ม) · Mock Test = โทนครีม-เขียว-เหลือง (แถบเขียว `bg_mock.jpg` เหรียญเขียว) · หน้าเฉลยแถบหัวเขียว/ส้มตามชนิดข้อ ทุกหน้าเปลี่ยนสีตามชุด (ป้าย กรอบ เลขข้อ เหรียญ)
- **ฟอนต์ Mali ทั้งชุด** (ครูลอง Itim แล้วเลือก Mali) · ข้อความมุมขวาล่าง "Math by T’Yasmin" ฟอนต์ Fredoka 600 · เลขหน้ากลางล่างซ้าย "สไลด์ n / 182"
- ป้ายตามชนิด: "ข้อจริง · ข้อสอบ สวช." และ "Mock Test 1/2", "Mock Test 2/2" (สะกด Mock Test ถูกต้อง)
- **หน้าโจทย์**: แถบหัว (วงกลมเลขข้อ ชื่อหัวข้อ) → กล่องโจทย์ (ฟอนต์ใหญ่ ปรับตามความยาว) → กรอบ "วิธีคิด" ใหญ่ → ช่อง "ตอบ"
- **โจทย์ระคนตัวเลขยาว ๆ (ข้อ 1–4)**: ประโยคนำอยู่บรรทัดแรก นิพจน์ทั้งหมดอยู่ **บรรทัดเดียว จัดกึ่งกลาง** ขนาดใหญ่ ถ้ายาวเกินให้ลดขนาดฟอนต์ ห้ามตัดแบ่ง
- **ตัวเลขกับหน่วยต้องอยู่บรรทัดเดียวกัน** (nowrap เช่น "35 คน") ทั้งในโจทย์และหน้าเฉลย และท้ายโจทย์ห้ามเหลือคำเดียวโดด ๆ (ผูกท้ายประโยค ~11 ตัวอักษร)

## 3. หน้าเฉลย (ผ่านการปรับหลายรอบ ตามที่ครูชอบ)
- แถบหัวสีเขียว ป้าย "✓ เฉลย" · ตัวตกแต่งดาว/จุดอ่อน ๆ
- **เหรียญ "คำตอบ" ตัวเลขใหญ่ อยู่มุมขวาล่าง** (ข้อที่ไม่มีรูปให้ลอยที่มุมจริง ๆ เพื่อให้กล่องวิธีคิดกว้างเกือบสุดขอบ; ข้อที่มีรูป/ผังแท่งให้รูปอยู่คอลัมน์ขวาเหนือเหรียญ)
- **ผลลัพธ์ของแต่ละขั้นอยู่ติดเครื่องหมาย "="** ในบรรทัดเดียวกันเป็นป้ายไฮไลต์ (ไม่ให้ตกบรรทัดใหม่โดด ๆ) ขั้นสุดท้ายเป็นการ์ดเขียว/ส้มเข้มมีเครื่องหมายถูก
- **ถ้าสมการยาวเกินบรรทัด**: ลดขนาดฟอนต์ของข้อนั้นก่อนจนอยู่บรรทัดเดียว (ไม่ต่ำกว่า ~17 pt) ถ้ายังไม่พอให้ใช้ 2 บรรทัด **โดยย้ายเนื้อหาช่วงที่ต่อเนื่องกันลงบรรทัดใหม่ทั้งช่วง** (ตัดที่ " → ", " · ", วงเล็บอธิบาย, "ดังนั้น", หลังจุลภาค) ห้ามทิ้งเศษ เช่น "14 =" หรือคำตอบไว้บรรทัดเดียวโดด ๆ; กลุ่ม "นิพจน์ท่อนสุดท้าย = ผลลัพธ์" ต้องไม่ถูกแยก
- **รูปแบบเฉลยผสมตามชนิดโจทย์**
  - ข้อคำนวณต่อเนื่อง (1, 2, 3, 4, 6, 8, 10, 11, 14, 16, 24, 25, 27, 29): **ขั้นบันได** การ์ดเยื้องขวาทีละขั้น + ลูกศรชี้ลง ฟอนต์ใหญ่ถึง 30 pt
  - โจทย์ปัญหา: **ผังแท่ง/แผนภาพ** วาด SVG จากตัวเลขของแต่ละข้อ (`diag.py`): ข้อ 13 แท่งเปรียบเทียบร้อยละ, 15 แท่งเศษส่วน, 17 เส้นเวลา ค.ร.น., 19 คอลัมน์ช่อง (ไก่กับกระต่าย), 22 สองแผงอายุ, 23 แท่งบวกย้อนกลับ
  - ข้อที่มีรูปเดิม (20, 21, 26, 28, 29, 30) ใช้รูปเดิมในคอลัมน์ขวา/ใต้ขั้นตอน
- **แถบเสริมทุกหน้าเฉลย (3 การ์ด)**: ✓ ตรวจคำตอบ (คิดเลขเฉพาะข้อ) · 💡 จุดสังเกต · ⚠ ข้อควรระวัง (ข้อความอยู่ใน `extras.py`, ฟอนต์ 11.5 pt) — ให้ครูอ่านทวนเพราะเขียนเอง

## 4. ข้อกำหนดทางเทคนิค/บทเรียนที่เจอ
- สร้างด้วย HTML + Playwright `page.pdf` (A4 landscape `preferCSSPageSize`) ฟอนต์ woff2 จาก @fontsource (npm pack แล้วคัดลอก `*-thai-*` และ `*-latin-*` ใส่ `ff/`; ใช้ `unicode-range` แยกไทย/ละติน) — เครือข่ายอนุญาต npm registry แต่ไม่อนุญาต cdn/unpkg
- **ห้ามใช้ `mix-blend-mode`/ฟิลเตอร์กับภาพใหญ่** ไฟล์พองเป็น 90 MB; ใช้ภาพพื้นหลังสำเร็จรูป (`bg_*.jpg`) และ PNG โปร่งแสงแทน ขนาดสุดท้ายควร ~15 MB
- ใน `hl()` ห้ามตัดสตริง HTML ตรงช่องว่างที่อยู่ในแท็ก (เคยทำให้ขึ้น `class="fr">` บนสไลด์) — ใช้ regex `' (?![^<]*>)'`
- เศษส่วนใช้ `<span class="fr">` ซ้อนบน-ล่าง; ถ้าอยู่ในเฉลยให้ห่อ `nowrap` ทั้งก้อน
- กราฟ/รูปข้อสอบที่ต้องนับ (เช่น ลูกบาศก์) ให้จำลองด้วยโปรแกรม (voxel render เทียบภาพ) และแจ้งครูให้ตรวจกับเฉลยทางการ
- ลำดับหน้าคงที่: หน้า 1 ปก, 2 สารบัญ, ข้อ n ข้อจริงอยู่หน้า `3+(n−1)*6` (หน้าเฉลยคือหน้าถัดไป)
- สคริปต์ปรับขนาดฟอนต์ใน JS ท้าย `deck.html` (ตัวแปร `data-done` บอกว่าเสร็จ) — `pdf.js` รอ `body[data-done]` ก่อนพิมพ์

## 5. รายการตรวจทานก่อนส่งทุกครั้ง
1. ทุกข้อมี 6 หน้า ชื่อป้ายถูก ("ข้อ n · ข้อจริง/Mock Test k") และเลขบนเหรียญตรงกับเฉลย (ใช้ pdftotext ตรวจทุกหน้า)
2. แทนคำตอบกลับทุกข้อ ทุกข้อมีคำตอบเดียวเป็นจำนวนเต็มบวก ข้อเสมือนไม่ซ้ำกัน และไฟล์สรุปครูตรงกับสไลด์
3. `node audit.js`: ไม่มีตัวเลขท้ายบรรทัดที่หน่วยตกบรรทัดถัดไป ไม่มีผลลัพธ์โดดบรรทัดเดียว ไม่มีโค้ด/`&nbsp;`/`NaN` หลุดมา
4. เปิดดูภาพตัวแทนทุกชนิด (ข้อคำนวณ, ผังแท่ง, ข้อมีรูป, ข้อ 26/30 รูปกว้าง, Mock Test) อย่างน้อยตัวละ 1 ข้อ และรายงานตามจริงว่าดูหน้าไหน
5. แจ้งข้อที่ตีความโจทย์เอง (ข้อ 12 เหรียญ 2 บาท, 14 ดอกเบี้ย 0.6% ครั้งเดียว, 26 นับสามเหลี่ยมในตัว A, 28 นับลูกบาศก์จากภาพ) ให้ครูตรวจกับเฉลยทางการ
